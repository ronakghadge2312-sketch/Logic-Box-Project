# 🔷 Logic Box — Pattern Generator & Number Analyzer

> A simple and interactive Python console application designed to practice **loops, conditional statements, user input, and basic number analysis**.

---

## 📌 About the Project

**Logic Box** is a menu-driven Python program that provides different pattern-generation options and a number-analysis tool.

The program runs continuously until the user selects the **Exit** option, making it simple and interactive for beginners learning Python programming.

---

## ✨ Features

### ⭐ Pattern Generator

Generate three different star patterns:

* 🔺 Right-angled Triangle
* 🔻 Pyramid
* ◀️ Left-angled / Right-aligned Triangle

### 🔢 Number Analyzer

The Number Analyzer can:

* Check whether numbers are **Even or Odd**
* Calculate the **sum of all numbers** within a selected range

### 🖥️ Interactive Menu

The program provides a simple menu with five choices:

```text
1. Right-angled Triangle
2. Pyramid
3. Left-angled Triangle
4. Analyze a Range of Numbers
5. Exit
```

## 💡 How It Works

When the program starts, it displays an interactive menu.

The user enters a choice from **1 to 5**.

### Option 1 — Right-angled Triangle

Enter the number of rows and the program generates a left-aligned triangle using `*`.

Example:

```text
*
**
***
****
*****
```

### Option 2 — Pyramid

The program uses spaces and stars to create a centered pyramid.

Example:

```text
    *
   ***
  *****
 *******
*********
```

### Option 3 — Left-angled Triangle

The program creates a right-aligned triangle.

Example:

```text
    *
   **
  ***
 ****
*****
```

### Option 4 — Number Analyzer

Enter a starting and ending number.

The program checks every number as **Even** or **Odd** and calculates the total sum.

Example:

```text
Number 1 is Odd
Number 2 is Even
Number 3 is Odd
Number 4 is Even

Sum of all numbers from 1 to 4 is: 10
```

### Option 5 — Exit

Selecting `5` terminates the program and displays:

```text
Goodbye!
```
